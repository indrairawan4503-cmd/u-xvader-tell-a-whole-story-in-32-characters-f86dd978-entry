A single Wi-Fi network name that tells a whole neighbourly story in 32 characters: the walls are thin, the neighbour heard everything, and something in the flat next door has quietly changed hands. It reads like a message the neighbour posted for the whole building to see.

## Run it

```sh
python3 main.py
```

Writes the network name to `/output/entry.txt`.
